# 07 — Recording Guide

Kept deliberately simple: screen recording + Steven's voice, no
complicated editing, no new equipment, no channel redesign.

## Setup (10 minutes, one time)

- Any built-in screen recorder (OBS, QuickTime, Windows Game Bar — whatever
  Steven already has) is enough. No new software to learn.
- Open, ahead of time: an empty spreadsheet with the header row from the
  script, and browser tabs for the two real source pages
  (`watertown-ny.gov/departments/WaterDepartment` and
  `edgartown-ma.us/departments/water`).
- Voice: built-in mic is fine for a first video. Don't buy anything for
  this.

## What Steven says on camera

Read the SAY lines in `01-FINAL-SCRIPT.md` naturally — not word-for-word
memorized, just hit the same points in the same order. It's fine to
re-record a section if it comes out awkward; no need for a single
unbroken take.

## What goes on screen, and when

| When | Show |
|---|---|
| Hook (0:00–0:30) | Title card or face-cam — either is fine |
| Body sections 1–8 | Screen recording per the shot list in `04-SHOT-LIST.md` |
| Conclusion | Title card again, or face-cam if Steven wants to bookend it |

## When to show the spreadsheet

Start empty (section 1), show it again with the source column filled
(section 6), then show it complete (section 7) — three brief touches, not
a long stare at rows.

## When to show the source page

Twice: the Watertown, NY page (name + email both visible — the clean
case) and the Edgartown, MA page (name + phone, no email — the honest
blank case). Linger a couple of seconds on each so the viewer can actually
read what's being pointed at.

## When to show AI

Once — the search/discovery moment in section 2. Keeping this to one
spot is deliberate: it visually reinforces the video's actual point that
AI's role is discovery, not the whole job.

## Editing

Minimal. Cut dead air between sections, add the two short text overlays
("NEVER GUESS AN EMAIL" and the QA checklist), and the bookend title
card. No music required; simple stock/royalty-free background track is
optional if it's already easy to add — not worth new tool-learning time
if it isn't.

## Time budget

Recording + rough cut should fit comfortably inside the 60-minute total
mission cap. If a section runs long, trim narration rather than add more
footage — the target is 4–7 minutes finished, not longer.
