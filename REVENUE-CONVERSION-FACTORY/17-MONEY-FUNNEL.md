# 17 — MONEY CONVERSION FUNNEL

## THE FUNNEL

```
  OPPORTUNITY FOUND
        ↓  ← qualification gate (14 + 15). Most things die here, correctly.
  QUALIFIED
        ↓  ← application / outreach written
  CONTACTED
        ↓  ← they respond
  RESPONSE
        ↓  ← conversation / interview / assessment
  INTERVIEW
        ↓  ← they decide
  OFFER
        ↓  ← terms agreed
  CONTRACT
        ↓  ← work performed
  DELIVERY
        ↓  ← money clears + feedback captured
  REVIEW
        ↓  ← they come back
  REPEAT
```

**The only two transitions that matter for strategy:**
**QUALIFIED → CONTACTED** (is Steven actually doing the work?) and
**CONTRACT → REPEAT** (is the work good enough to compound?).

Everything between them is throughput. Everything after REPEAT is the
business.

---

## STAGE DEFINITIONS — no wiggle room

| Stage | Counts ONLY when |
|---|---|
| **Opportunity found** | A real, specific, named target or posting is identified |
| **Qualified** | It passed `14` (profitability) and `15` (gates) |
| **Contacted** | Application submitted or message actually sent |
| **Response** | A human replied with something other than a form rejection |
| **Interview** | A live conversation or assessment took place |
| **Offer** | Specific work at a specific rate was formally offered |
| **Contract** | Terms agreed, work authorized to start |
| **Delivery** | Work completed and handed over |
| **Review** | **Money cleared Steven's account** + feedback captured |
| **Repeat** | The same buyer bought again, or referred someone who did |

**"Customer" and "revenue" mean cleared money. Not invoiced. Not promised.
Not in escrow. Not "they said yes."**

## PER-ENGINE FUNNEL SHAPES

These shapes are different, and comparing engines on the same conversion
metric is a mistake. What matters is **hours-in per dollar-out**.

### ENGINE 1 — AI EVALUATION
```
7 platforms applied → 4 assessments → 2 approved → 1-2 with real volume → paid weekly
```
Expected: **~50-60% application→assessment**, **~50% assessment→approved**,
but only **~25-30% approved→meaningful hours.** The drop-off is *throughput*,
not rejection — which is exactly why the plan onboards to seven, not two.
**Key metric: paid hours per week.** Not platforms approved.

### ENGINE 2 — AGENCY SUBCONTRACT
```
40 researched → 40 contacted → 4-8 replies → 2-4 calls → 1-2 pilots → 1 recurring
```
Expected: **10-20% reply**, **50% reply→call**, **50% call→pilot**,
**50% pilot→recurring.** Roughly **40 messages per recurring relationship.**
At 10/week that is a **4-week cycle** — this engine cannot be rushed and
shouldn't be judged before week 5.
**Key metric: reply rate.** It is the earliest signal that the message works.

### ENGINE 3 — CONTRACT ROLES
```
100 applications → 3-5 responses → 2-3 interviews → 1 offer
```
Expected: **2-5% application→interview** — this is *normal* and must be
understood in advance or Steven will misread silence as failure.
**Key metric: applications per week.** It is the only input he controls.

### ENGINE 4 — PRODUCTIZED
```
20 warm asks → 3-5 conversations → 1-2 sales → referrals
```
Warm network converts **5-10x** better than any cold channel.
**Key metric: conversion rate by channel** — this is how Steven learns where
his real market is.

## THE METRICS THAT COUNT

### Primary — track weekly
| Metric | Definition |
|---|---|
| Qualified opportunities | Passed the gates |
| Applications sent | Engine 3 |
| Outreach sent | Engine 2 + 4 |
| Replies | Human responses |
| Interviews / calls | Live conversations |
| Offers | Formal |
| Contracts | Agreed |
| **Revenue (cleared)** | Money in the account |
| Acquisition hours | Searching, writing, applying, following up, researching |
| Delivery hours | Only work someone is paying for |
| **TRUE $/HR** | **Revenue ÷ (acquisition + delivery)** |

### The one number that decides everything
> **TRUE $/HR = cleared revenue ÷ (acquisition hours + delivery hours)**

Gross $/hr flatters every model in this pack. True $/hr is what Steven
actually earns for the time he actually spends. **Below $15 → change the
channel, not the effort.**

### Secondary — diagnostic
Reply rate by channel · cost per reply (in hours) · time from contact to
cash · repeat rate · referral rate · **Connects spent** (target: **0**)

### Explicitly NOT metrics — the fake-progress traps
Proposals sent *(an input)* · files created · tools learned · courses
completed · videos watched · hours "working" · ideas generated · documents
written · **this pack**.

> Producing this document is not progress. Cleared money is progress.

## DIAGNOSTIC TABLE — read the funnel, don't just fill it in

| Symptom | Real problem | Fix |
|---|---|---|
| Few qualified opportunities | Searching wrong, or gates too tight | Widen search terms; re-check gates aren't screening out 70% matches |
| Qualified but not contacted | **Perfectionism** — the most likely failure | Cap application time at 12 min (see `19`) |
| Contacted, no replies | Message or targeting | **Rewrite after 10, not after 40** |
| Replies, no calls | Offer unclear or price wrong | Lead with the $150 QA pilot |
| Calls, no offers | Positioning or trust gap | Use the boundary line; offer money-back pilot |
| Offers, bad rates | Anchoring too low | Use published data: SOP $28-47/hr |
| Contracts, low true $/hr | Underpricing or scope creep | Run `14` before accepting, not after |
| No repeats | Delivery or follow-up gap | Deliver early; ask for the next piece at handover |
