# 25 — SEVEN PATHS TO THE FIRST $1,000

All figures use **cleared revenue** and **all-in hours** (acquisition +
delivery). Capacity ceiling: **8-12 hrs/week.**

---

## MODEL 1 — PURE AI EVALUATION ⭐ MOST LIKELY

| | |
|---|---|
| **Composition** | 45 paid hours × $22/hr average |
| **Revenue** | **$990** |
| **Sales required** | **Zero.** Nobody has to be persuaded. |
| **Acquisition burden** | ~4 hrs total — seven applications + assessments |
| **Delivery hours** | 45 |
| **All-in hours** | **49** → **$20.20/hr true rate** |
| **Time to $1,000** | **5-7 weeks** at 8 hrs/week |
| **Likelihood** | **~65%** — the highest in this list |

**Why it wins on probability:** the only variable is throughput. Rate is
contractual, no client has to say yes, no portfolio is needed, and payment
schedules are published. It is the least *exciting* path and by a wide margin
the most *certain*.

**The failure mode:** approved on one platform with 4 hrs/week available →
$1,000 takes 11 weeks. **Mitigation is the whole plan: onboard to 4+
platforms.**

## MODEL 2 — PRODUCTIZED VIA WARM NETWORK ⚡ FASTEST IF IT WORKS

| | |
|---|---|
| **Composition** | 4 × Sheet Rescue ($95) + 2 × SOP ($250) + 1 × Intake Form ($225) |
| **Revenue** | **$1,105** |
| **Sales required** | **7** |
| **Acquisition burden** | ~6 hrs (25 warm asks + conversations + follow-up) |
| **Delivery hours** | ~18 (4×1.5 + 2×3 + 1×4) |
| **All-in hours** | **24** → **$46/hr true rate** |
| **Time to $1,000** | **3-6 weeks** *if the network converts* |
| **Likelihood** | **~30%** |

**Best economics in the list by a distance** — $46/hr because warm
acquisition is nearly free. Also the **highest variance**: it depends
entirely on whether Steven's specific network contains seven buyers, which
nobody knows yet.

**Read it early:** 25 warm asks producing zero conversations means this model
is closed. That is a two-week, two-hour test — cheap to run and decisive.

| **Revenue** | **$1,064** |
| **Sales required** | **1** — one agency, then repeat work |

**This is the only model in the list that gets better every month.**

## WHAT THE TABLE ACTUALLY SAYS

**1. Rate and probability run in opposite directions.**
The warm-network model pays **$46/hr** and has a **30%** chance. Pure AI
evaluation pays **$20/hr** and has a **65%** chance. Neither is "better" —
which is precisely why Steven runs both, and why the realistic blend sits in
the middle on both axes.

**2. The number of sales required is the real difficulty score.**
Model 2 needs seven strangers to say yes. Model 1 needs zero. **Steven has
never closed a sale, so a plan requiring seven of them is a plan built on an
untested assumption.** Model 1's zero is what makes it the anchor.

**3. Acquisition hours are where the models genuinely differ.**
Delivery hours cluster between 18 and 55. Acquisition ranges from **4 hours
to 25**. The winning models aren't the ones with better work — they are the
ones with cheaper access to buyers.

**4. Month two is a different table.**
Models 3 and 4 pay their acquisition cost once. Their **month-two** true
rates are ~$32/hr and ~$34/hr — the best in the list. Model 1's stays at
~$20/hr forever. **The first $1,000 and the tenth $1,000 come from different
places, and the plan is deliberately built to run both.**

## THE RECOMMENDED PATH

**Run Model 5 (the blend), anchored on Model 1, while building Model 3.**

- **Model 1 is the floor** — it is nearly certain and requires no persuasion.
- **Model 2 is the lottery ticket** — two hours of warm asks; if it hits,
  it's the best economics available.
- **Model 3 is the investment** — slowest to $1,000, best position afterward.
- **Model 4 runs free in the background** — 5 applications a day costs
  nothing and one offer changes everything.
- **Model 6 is a bounded 10-hour experiment** for the case study.
- **Model 7 is the safety net** — it exists so Steven knows the downside is
  slow, not zero.

**Expected first $1,000: week 6-8.**

Not two weeks. Not "this month if you hustle." Six to eight weeks of
consistent 8-12 hour weeks, most of it from a channel where nobody has to be
convinced of anything.

That is a real, defensible number — and it is achievable without spending a
dollar or a single one of the remaining 14 Connects.
