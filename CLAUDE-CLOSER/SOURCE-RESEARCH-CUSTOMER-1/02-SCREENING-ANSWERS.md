## Question 2: "What would you do for a town of 800 people whose website is one page with a phone number?"

> I wouldn't stop at that one page. I'd check whether the county covers
> water/public works for a town that small — some do. I'd search the
> state's Rural Water Association directory, since most states run one
> and several publish system-level contacts. I'd also check the state's
> drinking water or wastewater program for an "operator of record" if
> that's public. LinkedIn only comes in to confirm a name and title if
> I've already found one elsewhere — never as the source for an email.
> If none of that turns up a named, verifiable contact, I'd record the
> phone number from the town's own page as the main contact channel,
> leave the name/email fields blank, and note that no individual contact
> was publicly available. I'd rather hand back an honest blank than a
> fact that looks real but isn't.

Both answers are ready to paste as-is if the client asks them verbatim in
a message thread, or to speak from naturally if asked on a call.
