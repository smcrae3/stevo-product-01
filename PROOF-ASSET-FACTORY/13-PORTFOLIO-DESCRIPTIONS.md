## 1. SOP / Process Documentation

**Title:** Customer Inquiry Intake SOP — From Informal Process to Repeatable
Procedure

**60-word summary:** A complete standard operating procedure for a
customer-inquiry intake process, covering roles, step-by-step procedure,
urgency classification logic, exception handling, and escalation rules —
plus a process map showing the happy path, exception path, and escalation
path as one connected flow. Built to demonstrate process-interview method
and documentation standard, not describing a paid engagement.

**Skills:** Process documentation · SOP writing · Decision-table design ·
Exception handling · Escalation logic

**Tools:** Google Docs/Sheets · AI-assisted drafting (Claude/ChatGPT) ·
process-mapping conventions

assisted), personal verification of every decision point, formatting

**Disclaimer:** Demonstration only. Fictional company. Not client work.

## USAGE NOTES

  description; attach the full asset as a linked document.

  with a "view full sample" link.

  summary as the post caption if sharing individually.
- **Agency outreach attachments:** use only the title and a one-sentence
  trimmed version of the summary in the email body — the full 60-word
  version is for the attached document itself, not the pitch.
