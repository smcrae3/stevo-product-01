# 22 — WARM-NETWORK PROOF MESSAGES

These differ from the prior mission's warm-network scripts
(`24-WARM-NETWORK-PLAN.md`) in one specific way: **proof is now the hook,**
because it didn't exist before. Where the prior scripts announced "I do
this kind of work now," these lead with "here's a sample so you can see
exactly what I mean" — a stronger, more concrete opener now that real
finished samples exist.

**Same rules as before: no hype, no "please support my business," always
an easy out.**

## WHY "HERE'S A SAMPLE" OUTPERFORMS "HERE'S WHAT I DO"

The prior mission's warm-network scripts (necessarily, since no samples
existed yet) asked people to take Steven's description of his services on
faith. These versions ask for nothing on faith — the recipient can open the
link and judge the actual work in under a minute. That shift moves the
message from "here's an announcement" to "here's evidence," which is a
meaningfully easier thing for someone to act on or forward to someone else,
because they're not vouching for a claim, they're forwarding a demonstrated
result.

**The practical difference in the field:** replace the equivalent scripts
in the prior mission's `24-WARM-NETWORK-PLAN.md` with these versions once
the proof-portfolio link exists (it does, as of this mission) — the
segments, cadence, and campaign structure in that file remain unchanged and
still apply.
