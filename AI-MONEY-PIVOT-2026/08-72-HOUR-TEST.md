# 08 — 72-Hour Test

**Goal:** validate willingness to pay. Nothing more. Do not build anything
new.

## Hour 1
- Open the verified live job (Opportunity 1 in 07). Read Task 1 and Task 2
  in full.
- Score both tasks GREEN/YELLOW/RED using the instrument in
  `CLAUDE-CLOSER/LATEST-CLOSER-DECISION.md`.
- If both GREEN or YELLOW-resolvable: send the proposal already drafted in
  this session's earlier evaluation (adjust the two questions if the task
  text answers them already).

## Hours 2–4
- Run the search recipe in 07-LIVE-OPPORTUNITIES.md.
- Score every hit against the same instrument. Bid on any that pass —
  budget up to ~3 bids total across the 72 hours (roughly 30 Connects,
  under $5).
- Do not bid on anything scoring RED or NO on "can Steven explain this
  without hiding behind AI."

## Day 1 (remainder)
- List one workflow template on Gumroad from an existing working asset
  (the lead-response Make scenario), per 05-TOP-5.md #4. This is a
  reversible, zero-cost, async action — post it and move on, don't refine
  it for hours.
- No paid promotion. No posting it anywhere outside Gumroad's own listing.

## Day 2
- Check all bids for replies. Respond same-day, in writing, text-first.
- If a reply arrives requesting a call: use the Call Cheat Sheet in
  `CLAUDE-CLOSER/LATEST-CLOSER-DECISION.md` before joining.
- No new bids required today — let Day 1's bids surface signal first.

## Day 3
- Check Gumroad listing for views (not sales — 3 days is too short for
  organic discovery to show much, this is a floor-setting data point, not
  a verdict).
- Final tally against the success/failure thresholds below.
- Decide: continue this exact motion for another 7 days, or revisit
  02-BUSINESS-MODEL-RANKING.md if the signal genuinely contradicts it.

## Success thresholds (any one of these = signal worth continuing)
- **Listing viewed:** at least 1 client views a submitted proposal
  (visible in Upwork's proposal status).
- **Buyer response:** any reply, even a question or a "not right now."
- **Conversation:** back-and-forth exchange with a buyer.
- **Sale:** the $150 job, or any other bid, is awarded.

## Failure threshold (triggers a re-think, not a shutdown)
- **Zero** proposal views, **zero** replies, across all bids sent in the
  72 hours, despite scoring correctly against the instrument. That would
  be the first real evidence the channel itself — not just the outbound
  cold-touch method already abandoned — needs reconsidering. One 72-hour
  window with 2–3 bids is a small sample; don't overreact to it alone, but
  don't ignore it either if it repeats a second window.

## What this test explicitly does NOT include
- No ad spend.
- No new store, no new product build.
- No public posting outside Gumroad's own listing mechanism and the
  Upwork proposals themselves (which the platform's own flow requires to
  bid at all — this is not "public posting" in the sense the mission
  restricts, it's using the marketplace as designed).
- No purchases.
- Nothing submitted by AI — every bid, message, and listing is Steven's
  own action, using drafted material as a starting point.
