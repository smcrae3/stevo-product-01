# 10 — One 72-Hour Experiment (Lane A only)

One test, not three businesses, per instruction. Supersedes the prior
72-hour test in scope (same lane, sharper on the verification lesson).

## Day 1

- Run the search recipe (01-AUTOMATION-DEMAND.md / 09-LIVE-TOP-3.md) live
  on Upwork and Fiverr.
- For every candidate, including the four leads listed in 09, apply the
  three-step verification check personally before anything else.
- Bid only on listings that pass all three checks. Budget: up to 3 bids
  (~30 Connects, under $5).
- Do NOT bid on the "Automation manager for Make.com" job — confirmed
  hard SKIP this session.

## Day 2

- Check all Day 1 bids for views/replies.
- If nothing passed verification on Day 1, re-run the search once more
  with a widened time window (Upwork listings refresh constantly; a
  same-day sweep can miss a fresh post by hours).
- Respond same-day to any reply, in writing, text-first. Use the Call
  Cheat Sheet in `CLAUDE-CLOSER/LATEST-CLOSER-DECISION.md` only if a call
  is requested.

## Day 3

- Final tally against the thresholds below.
- Log whatever was learned — including a null result — into
  `CLAUDE-CLOSER/LATEST-CLOSER-DECISION.md`, since that's the file this
  workflow already treats as the live decision record.

## Success threshold (any one)
- A verified, complete listing is found and bid on within Day 1.
- Any buyer reply, view, or award within the 72 hours.

## Failure threshold
- Zero listings in the search recipe pass the three-step verification
  check across the full 72 hours (i.e., every candidate found is
  incomplete, closed, or clearly RED) — this would be a genuinely new and
  concerning signal about the current live inventory, worth flagging
  back rather than pushing through.

## What this test does not include
No ad spend, no new product build, no proposals submitted by AI (Steven
submits, using drafted material as a starting point only), no purchases,
no public posting beyond the marketplace's own bidding mechanism.
